# 利用規約

本利用規約（以下「本規約」といいます。）は、shukanlog（以下「本サービス」といいます。）の利用条件を定めるものです。

本サービスを利用する方（以下「利用者」といいます。）は、本規約の内容を確認し、同意した上で本サービスを利用するものとします。

## 第1条（適用）

1. 本規約は、本サービスの提供条件および本サービスの利用に関する運営者と利用者との間の権利義務関係を定めることを目的とします。
2. 本サービス上に掲載するルール、注意事項その他の案内は、本規約の一部を構成するものとします。
3. 本規約の内容と前項の案内等の内容が異なる場合は、本規約の定めが優先して適用されます。

## 第2条（本サービスの内容）

1. 本サービスは、利用者が自ら登録した健康習慣・服薬対象等に基づき、日々の実施状況を記録し、週間・月間の継続状況を振り返るためのセルフマネジメントサービスです。
2. 本サービスの具体的な機能、提供方法その他の内容は、本サービス上に表示するものとします。
3. 本サービスは現在無料で提供しています。ただし、運営者は、将来、本サービスの全部または一部の提供条件を変更することがあります。
4. 本サービスは、医療行為、医学的診断または治療に関する判断を行うものではありません（詳細は第11条を参照してください）。

## 第3条（利用登録）

1. 本サービスの利用を希望する者は、本規約およびプライバシーポリシーに同意した上で、運営者が定める方法により利用登録を行うものとします。
2. 利用者は、登録にあたり、正確かつ最新の情報を提供するものとします。
3. メールアドレスおよびパスワードの登録その他必要な手続が完了した時点で、利用登録が完了します。
4. 運営者は、次のいずれかに該当すると判断した場合、利用登録を拒否し、または登録後に利用を制限もしくは停止することがあります。
   - 登録内容に虚偽、誤記または記載漏れがある場合
   - 他人になりすまして登録した場合
   - 過去に本規約に違反したことがある場合
   - その他、運営者が本サービスの利用を適当でないと合理的に判断した場合

## 第4条（登録情報の管理）

1. 利用者は、登録した情報に変更が生じた場合、運営者が定める方法により速やかに変更するものとします。
2. 利用者は、登録したメールアドレスおよびパスワードその他本サービスへのログインに使用する認証情報を、自己の責任において適切に管理するものとします。
3. 登録されたメールアドレスおよびパスワードを用いて行われた本サービスの利用については、当該利用者本人による利用として取り扱う場合があります。
4. 利用者は、認証情報を第三者に利用させ、または貸与、譲渡、名義変更、売買等をしてはならないものとします。

## 第5条（禁止事項）

利用者は、本サービスの利用にあたり、次の行為を行ってはなりません。

1. 法令または公序良俗に違反する行為
2. 犯罪行為に関連する行為
3. 他人になりすます行為
4. 虚偽または不正確な情報を登録する行為
5. 本サービスのサーバー、ネットワークその他のシステムに過度な負荷を与える行為
6. 本サービスへの不正アクセス、または他の利用者のアカウントへの不正アクセスを試みる行為
7. 本サービスの正常な運営を妨害する行為
8. 本サービスまたは第三者の権利または利益を侵害する行為
9. 本サービスを不正な目的で利用する行為
10. その他、運営者が不適切と合理的に判断する行為

## 第6条（知的財産権）

本サービスに含まれる文章、画像、デザイン、プログラムその他のコンテンツに関する著作権その他の知的財産権は、運営者または正当な権利を有する第三者に帰属します。

利用者は、法令で認められる場合を除き、これらを無断で複製、転載、改変、配布その他の方法で利用してはなりません。

なお、利用者が本サービスに登録した記録データ（習慣・服薬・運動・カロリー等の記録内容）自体の権利は利用者に帰属します。

## 第7条（本サービスの停止・中断）

運営者は、次のいずれかに該当する場合、利用者への事前の通知なく、本サービスの全部または一部の提供を一時的に停止または中断することがあります。

1. システムの保守、点検または更新を行う場合
2. サーバー、通信回線その他の設備に障害が発生した場合
3. 本サービスが利用する外部サービス（インフラ提供事業者を含みます）に障害が発生した場合
4. 地震、火災、停電その他の不可抗力によりサービスの提供が困難となった場合
5. その他、運営者が本サービスの提供を継続することが困難であると判断した場合

## 第8条（本サービスの変更・終了）

1. 運営者は、必要に応じて本サービスの内容を変更し、または提供を終了することがあります。
2. 本サービスの全部を終了する場合は、緊急その他やむを得ない場合を除き、本サービス上での掲示その他適切な方法により事前に周知するよう努めます。
3. 本サービスの提供を終了する場合、運営者は、可能な範囲で利用者が自身の記録データを確認・保存できる猶予期間を設けるよう努めます。

## 第9条（利用終了・データ削除）

1. 利用者は、運営者が定める方法により、本サービスの利用終了（退会）および登録情報・記録データの削除を申し出ることができます。
2. 運営者は、前項の申出があった場合、本人確認を行った上で、合理的な期間内に登録情報および記録データを削除します。ただし、法令上保存が必要な情報についてはこの限りではありません。

## 第10条（保証の否認および免責）

1. 運営者は、本サービスが利用者の特定の目的に適合すること、継続的に利用できること、エラーや障害が発生しないことその他本サービスについて完全性、正確性、有用性等を保証するものではありません。
2. 運営者は、本サービスに記録された内容の正確性について保証するものではなく、記録の入力誤りその他利用者自身の入力に起因する結果について責任を負いません。
3. 運営者の責めに帰すことができない事由によって利用者に生じた損害について、運営者は責任を負いません。
4. 本サービスに関して運営者が損害賠償責任を負う場合であっても、運営者に故意または重大な過失がある場合を除き、その責任は、利用者に現実に発生した通常かつ直接の損害の範囲に限られるものとします。
5. 前各項の定めは、消費者契約法その他の法令により運営者の責任を制限することが認められない場合には、その範囲では適用されません。

## 第11条（医療行為に関する免責）

1. 本サービスは、利用者自身による習慣・服薬・運動・カロリー等の記録およびその振り返りを支援するものであり、医療行為、医学的診断、治療方針の提案または投薬に関する判断を行うものではありません。
2. 本サービスに表示される分析結果、達成率その他の情報は、記録データを単純に集計したものであり、医学的な評価または健康状態の診断を意味するものではありません。
3. 服薬の要否、投薬量の変更その他健康・医療に関する判断は、必ず医師その他の専門家にご相談ください。運営者は、本サービスの利用または不利用に起因する健康上の結果について責任を負いません。

## 第12条（個人情報の取扱い）

運営者は、本サービスの利用に伴い取得する利用者の個人情報（要配慮個人情報を含みます）を、別途定めるプライバシーポリシーに従って適切に取り扱います。

## 第13条（通知・連絡）

1. 運営者から利用者への通知または連絡は、本サービス上への掲載、登録されたメールアドレスへの送信その他運営者が適切と判断する方法により行います。
2. 利用者から運営者への連絡は、本サービス上に掲載する問い合わせ窓口を通じて行うものとします。

## 第14条（本規約の変更）

1. 運営者は、法令の変更、本サービスの変更その他必要がある場合、本規約を変更することがあります。
2. 本規約を変更する場合、変更内容および効力発生日を、本サービス上への掲載その他適切な方法により周知します。
3. 変更後の本規約は、前項に定める効力発生日から適用されます。

## 第15条（分離可能性）

本規約のいずれかの条項またはその一部が法令等により無効または執行不能と判断された場合でも、本規約のその他の部分は引き続き有効に存続するものとします。

## 第16条（準拠法・管轄）

1. 本規約の解釈および適用には、日本法を準拠法とします。
2. 本サービスに関して運営者と利用者との間に紛争が生じた場合には、東京地方裁判所または東京簡易裁判所を第一審の合意管轄裁判所とします。
