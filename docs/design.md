# shukanlog デザイン仕様書

shukanlog(Cloudflare版)の見た目と操作のルール。実装はこの文書を正とする。

- デザインの元データ: claude.ai の Design キャンバス「shukanlog デザイン」(https://claude.ai/artifact/PKhrofv56c7iCKkW6tcKeA)。人が確認するための参照先で、実装時に読む必要はない
- 週タブ・月タブの詳細な仕様は `docs/week-month-tabs.md` を参照する

## 1. 基本方針

- 色(青・琥珀)は記録の状態を表すときだけに使う。ボタン・選択中のタブなどの操作は、文字色(#1F1F1D)で表す
- 状態は色だけでなく、記号の形(◯△×)でも伝える(WCAG 1.4.1)
- 押せる要素の大きさは44×44px以上にする(見た目が小さい場合は余白で確保する)
- 画面幅 1024px 以上をPCレイアウト(2列)、それ未満をスマホレイアウト(1列)とする

## 3. 文字

| 用途 | フォント | 太さ |
|---|---|---|
| 見出し・日付・数字・サービス名 | Zen Maru Gothic | 500, 700 |
| 本文・ラベル・ボタン | Zen Kaku Gothic New | 400, 500, 700 |

- フォールバック: `"Hiragino Sans", sans-serif`
- 本文 15〜16px、補足 13px、最小 11px(月タブのマス内のカロリーのみ)
- フォントは Fontsource(`@fontsource/zen-maru-gothic`、`@fontsource/zen-kaku-gothic-new`)で自前配信し、使う太さのCSSだけを読み込む。Google Fonts には接続しない

## 4. アイコン

- 汎用アイコンは Lucide(`lucide-react`)を使う: `Settings`(設定)、`ChevronLeft` / `ChevronRight`(前後の移動・戻る・項目の矢印)、`Plus`(記録する)。線の太さ 2
- ◯△× の状態記号は `StatusIcon` コンポーネント1つにまとめる。記号・色・読み上げ用のラベルの対応はこのコンポーネント内だけで定義する
  - 形: ◯=円(半径7/20)、△=三角、×=バツ(いずれも線のみ、線の太さ 2.4〜3)
  - 大きさ: 記録ボタン 20〜22px、週タブ 20〜24px、月タブ 14px(スマホ)/20px(PC)、凡例 16px
  - 未記録は何も描かない(空欄)
- フォントとアイコンのライセンス表記(OFL 1.1、ISC/MIT)を「ライセンス」ページに載せる

## 5. レイアウト

### スマホ(幅 390px 基準)

- ヘッダー(高さ56px): 左にサービス名、右に設定アイコン(44×44)
- その下に、月・週・日の切り替え(左右20pxの余白、高さ44pxのボタン3つ、順番は **日・週・月**)
- その下に、期間の移動(前へ・期間の見出し(h1)・次へ)
- 本文は左右20pxの余白、カード同士の間隔12px

### PC(幅 1280px 基準)

- ヘッダー(高さ72px、下に区切り線): 左にサービス名、中央に月・週・日の切り替え(幅300px)、右に「設定」(アイコン+文字)
- 本文は幅1040pxで中央寄せ
- 日タブ・週タブは左右 7:5、月タブは 8:4 の2列
- 設定とそのサブページ(メールアドレス・パスワードの変更、退会)は幅640pxの1列
- 認証画面(ログインなど)は幅440pxのカード(利用規約への同意だけ560px)

## 6. 部品

| 部品 | 仕様 |
|---|---|
| カード | 背景 #FFFFFF、枠線 1px #E3E2DC、角丸 16px(PCは18px)、内側の余白 14〜20px |
| 主要ボタン | 塗り #1F1F1D、文字 #FFFFFF、高さ52px、角丸14px |
| 補助ボタン | 背景 #FFFFFF、枠線 1.5px #1F1F1D、高さ48〜52px |
| 取り消せない操作のボタン | 塗り #B42318、文字 #FFFFFF(退会する・記録を削除する の最終確認のみ) |
| 入力欄 | 高さ48px、枠線 1px #8A8983、角丸12px、文字16px(iOSで拡大されないように) |
| エラー表示 | 入力欄の下に #B42318 の13pxの文章。`aria-invalid` と `aria-describedby` で入力欄と関連付ける |
| パスワード欄 | 右に「表示/隠す」ボタン(`aria-pressed`) |
| トースト | 画面下部中央、塗り #1F1F1D の丸い帯、文字 #FFFFFF 14px。`role="status"`。2秒で消える |
| カロリーの入力 | スマホは下からせり上がるシート、PCは中央のダイアログ(幅480px)。`role="dialog"` と `aria-modal` |
| スイッチ | 見た目 52×32px、押せる範囲 60×44px。`role="switch"` と `aria-checked` |
| スケルトン | 読み込み中はカードの形の灰色(#ECEBE6)の枠を表示し、`aria-busy` と読み上げ用の文言を付ける |

## 7. 操作のルール

- 記録ボタン(◯△×)は押した瞬間に保存し、「保存しました」とトーストを出す
- 選択中のボタンをもう一度押すと未記録に戻し、「記録を取り消しました」とトーストを出す。各習慣のカードに「もう一度押すと取り消し」と添える
- 保存に失敗したら表示を元に戻し、「保存できませんでした。通信状況を確認して、もう一度お試しください」とトーストを出す
- 期間の移動で今日を含まない期間を表示しているときだけ「今日に戻る」ボタンを出す。今日を含む期間では「次へ」を薄くして押せないようにする(`aria-disabled`)
- カロリーの記録は、カードの見出しの横の「記録する」から追加し、記録の行を押すと編集する。削除は編集画面で2段階の確認をする
- ログアウトは確認なしで実行し、ログイン画面に「ログアウトしました」と表示する
- 各画面の主見出し(h1)は、日付・期間の表示、またはページ名にする

## 9. 認証まわりの決定事項

- メールアドレスの確認・パスワードの再設定・メールアドレスの変更は、リンクではなく **6桁のコード** で行う(ホーム画面から開いたアプリとメールのリンクでブラウザが分かれる問題を避けるため)
- 確認コードの有効期限は10分、再送は60秒に1回
- パスワードは8文字以上
- 新規登録に Cloudflare Turnstile を表示する
- パスワードを変更すると、ほかの端末のセッションを無効にする
- 退会は即時に論理削除し、30日後に物理削除する。30日以内に同じメールアドレスでログインすると退会を取り消せる
