# 週タブ・月タブ 仕様書

shukanlog(Cloudflare版)のメイン画面における、週タブと月タブの仕様。色・記号・部品の共通ルールは `docs/design.md` を参照する。

## 1. 共通仕様

### 1.1 URLと期間の決め方

- 週タブ: `/app?tab=week&date=YYYY-MM-DD`
- 月タブ: `/app?tab=month&date=YYYY-MM-DD`
- `date`は期間内の任意の1日を表す。週タブは`date`を含む週(月曜〜日曜)、月タブは`date`を含む月を表示する
- `date`が未指定・不正な形式・未来の日付の場合は、今日の日付として扱う
- 上部の切り替え(順番は **日・週・月**)で表示を変えても`date`は保持する

### 1.2 週の始まり

- 週は**月曜始まり**とする(週タブ、月タブのカレンダーの両方)

### 1.3 期間の移動

- 前へ: 週タブは`date`を-7日、月タブは-1か月する。移動先の月に同じ日が無い場合は、その月の末日にする(例: 3月31日 → 2月28日)
- 次へ: 今日を含む期間を表示しているときは押せない(薄く表示し`aria-disabled="true"`)。それ以外は+7日/+1か月する。移動先が今日より後になる場合は今日にする
- 今日を含まない期間を表示しているときだけ「今日に戻る」ボタンを表示する
- 期間の表示を、その画面の主見出し(h1)にする

### 1.4 日付とタイムゾーン

- すべての日付は日本時間(Asia/Tokyo)で扱う
- 「今日」はクライアントとサーバーのどちらでも日本時間で判定する(Workersの実行環境はUTCのため、サーバー側でも明示的に変換する)

### 1.5 集計の対象となる日(分母)

- 分母は、期間内のうち「アカウント作成日以降」かつ「今日以前」の日数とする

### 1.6 状態の表示

| 状態 | 記号 | 色 |
|---|---|---|
| 達成(completed) | ◯ | 青 #2563EB |
| 一部達成(partial、3段階の習慣のみ) | △ | 琥珀 #D97706 |
| 未達成(not_completed) | × | グレー #71717A |
| 未記録(記録なし) | 何も表示しない(空欄) | - |

- 記号は `StatusIcon` コンポーネントで描画し、必ず白(#FFFFFF)のマスの上に置く
- 連続達成日数(streak)は表示しない
- 画面内に凡例(◯達成 △一部達成 ×未達成 空欄 = 未記録)を表示する。スマホは画面下部、PCは週タブでは期間の見出しの右、月タブでは右の列
- 週・月の集計には「達成」「一部達成(3段階の習慣のみ)」「未達成」「未記録」を状態別に表示し、「対象 N日」を分母として表示する
- 集計の対象日は1.5の分母と同じ。未記録数は対象日から各状態の日数を除いて求め、作成日前と今日より後の日は未記録に含めない

### 1.7 日付のマス

- 今日以前のマスは、その日の日タブ(`/app?tab=day&date=その日`)へのリンクにする
- 未来のマスはリンクにせず、破線の枠(#D6D5CF)で、マス全体を不透明度0.55で表示する
- 今日のマスは枠線を 2px #1F1F1D にする
- 各マスに読み上げ用のラベルを付ける
  - 週タブ: 「9月23日 服薬 未達成」
  - 月タブ: 「9月3日 服薬 達成 運動 一部達成 1950kcal」(カロリー記録がない日は「カロリー記録なし」、未来の日は「9月26日 未来の日」)

### 1.8 読み込み中・エラー・記録なし

- 読み込み中はスケルトン、取得失敗時は「記録を読み込めませんでした」と「再読み込み」ボタンを表示する(日タブと同じ形式)
- 期間内に記録が1件も無い場合も、マス目はすべて空欄で表示し、あわせて「この期間の記録はまだありません」と表示する

### 1.9 カロリー記録をオフにしている利用者

- 週タブのカロリーのカード、月タブのマス内のカロリー、月間サマリーの平均カロリーを表示しない
- 月タブのマスの見方の説明を「左:服薬 右:運動」にする

## 2. 週タブ

### 2.1 期間の表示

- 形式: `9/21(月)〜9/27(日)`
- 週が年をまたぐ場合、または今年以外の週の場合は年も表示する(例: `2026/12/28(月)〜2027/1/3(日)`)

### 2.2 習慣の達成状況

- 記録対象(active)の習慣ごとに1行、月曜〜日曜の7マスを並べる(行の順番は日タブと同じ: 服薬 → 運動)
- 曜日の見出しの下に日付を表示する(スマホは曜日の下に数字、PCは「月 21」)
- マスの大きさ: PC 高さ56px
- スマホ(1024px未満)は横幅を確保できないため、日付ごとの縦型一覧で表示する。各日付の行に曜日・日付と、その日の各習慣の状態をまとめ、今日以前の行全体を日タブへのリンクにする。行の操作領域は幅・高さとも44px以上とし、未来日はリンクにしない
- PC(1024px以上)は習慣ごとの行と月曜〜日曜の7列を維持し、各マスを日タブへのリンクにする
- 各行の下に、期間の集計を状態名付きで表示する
  - 服薬(2段階): `達成 4 未達成 0 未記録 1 / 対象 5日`
  - 運動(3段階): `達成 2 一部達成 1 未達成 1 未記録 1 / 対象 5日`

### 2.3 カロリー

- 月曜〜日曜の日別合計カロリーを棒グラフで表示する。棒の色は #57574F、棒の上に数値(桁区切りあり)、下に曜日。記録がない日は棒も数値も表示しない
- 見出しの横に `平均 1,718 kcal(記録 5日)` を表示する。平均は記録がある日だけで算出し、表示時に小数点以下を四捨五入して整数にする。1日も無い場合は「記録なし」とする
- 棒ごとに読み上げ用のラベル(「9月21日 1,950kcal」「9月26日 記録なし」)を付ける
- 目標カロリーは表示しない

## 3. 月タブ

### 3.1 期間の表示

- 形式: `2026年9月`

### 3.2 カレンダー

- 月曜始まりの7列(最大6行)。前月・翌月の日付のマスは空欄
- 各マスに表示するもの
  - 日付の数字(左上)
  - 服薬と運動の状態記号を左右に並べる(左: 服薬、右: 運動。未記録の側は空欄のまま位置を保つ)
  - その日の合計カロリー(下)。単位は付けない。スマホは桁区切りなし・11px、PCは桁区切りあり・13px。記録がない日は表示しない
- マスの大きさ: スマホ 高さ62px、PC 高さ88px
- マスの見方の説明「左:服薬 右:運動 下:kcal」を、スマホはカレンダーの上、PCは右の列に表示する

### 3.3 月間サマリー

- 服薬: `達成 19 未達成 2 未記録 4 / 対象 25日`
- 運動: `達成 9 一部達成 8 未達成 3 未記録 5 / 対象 25日`
- 平均カロリー: `1,860 kcal(記録 21日)`。小数点以下は表示時に四捨五入して整数にする
- スマホはカレンダーの下に3列、PCは右の列に縦に並べる

## 4. データ取得(実装の指針)

- 期間(開始日・終了日)を指定して、その期間の習慣の記録とカロリーの日別合計をまとめて返すAPIを1本用意する
  - 例: `GET /api/summary?from=2026-09-21&to=2026-09-27`
  - レスポンス: 日付ごとの「習慣IDと状態」の一覧、日付ごとの合計カロリー、アカウント作成日
- 期間の上限は42日とし、超える指定は400にする
- 期間の計算(週の開始日、月末、分母の日数、次へ・今日に戻るの可否)は純粋関数として `src/shared/domain/`(またはリポジトリの既存の構成に合わせた場所)に置き、単体テストを書く

## 5. 今回の対象外

- 前の週・前の月との比較
- 連続達成日数(streak)の表示
- 目標カロリーとの比較
- 日タブ以外からの記録の入力
