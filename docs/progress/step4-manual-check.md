# ステップ4 画面の動作確認(手動確認手順)

この環境ではブラウザを実際に操作できるツールが無かったため、`pnpm dev` を起動し、curlでAPIレベルの一連の流れが成立することを確認した(結果は docs/progress/step4.md のT17参照)。確認した流れ:

- 新規登録 → メール確認 → 同意 → 日タブの記録(習慣・カロリー) → GET /api/summary(週・月タブ相当)への反映
- 設定のカロリー記録の無効化 → 日タブ・週月タブ相当のAPIからカロリーが消える → 再度有効化
- メールアドレスの変更(確認コードの送信 → 確認 → 新しいメールアドレスでログイン)
- パスワードの変更(別端末を想定した2つ目のセッションが無効になり、今の端末はログインしたまま)
- 退会 → セッションの無効化 → 再ログインで取り消し(GET /api/meのjustCanceledWithdrawalがtrueになる)
- `/`・`/app`・`/terms`・`/privacy`・`/licenses`・存在しないパスがいずれもSPAのシェルを200で返す

上記の確認で不具合は見つからなかった。画面(React側)を実際にブラウザで操作して確認する場合は、以下の手順で行う。スマホ幅(390px程度)とPC幅(1280px程度、ブラウザの開発者ツールでレスポンシブ表示にする)の両方で確認する。ステップ3の手順(新規登録〜ログイン、日タブでの記録)は docs/progress/step3-manual-check.md を参照し、ここではステップ4で追加した範囲のみをまとめる。

## 準備

1. `.dev.vars.example` を `.dev.vars` にコピーし、`BETTER_AUTH_SECRET` をランダムな32文字以上の文字列に置き換える
2. `pnpm run db:migrate:local` でローカルD1にマイグレーションを適用する(ステップ4で追加したaccount_deletionテーブルのマイグレーションを含む)
3. `pnpm dev` でサーバーを起動する
4. 確認コードは開発用のメール送信(console)のため、ターミナルのログに出力される

## 確認項目(スマホ幅・PC幅の両方で)

### 日・週・月タブの表示と切り替え

- [ ] 日タブで習慣を記録した後、週タブ・月タブを開くと、その日のマスに記録した状態(◯△×)が反映されている(リロードしなくても反映される)
- [ ] 週タブ・月タブのマスのうち、今日以前のマスを押すとその日の日タブへ移動する。未来のマスは押せない(破線・薄い表示)
- [ ] 週タブの習慣ごとの集計(◯の数/分母)、カロリーの棒グラフと平均が表示される。棒グラフは記録がない日は表示されない
- [ ] 月タブの月曜始まりのカレンダー(前月・翌月は空欄)、各マスの服薬(左)・運動(右)の記号とカロリー(スマホは桁区切りなし、PCは桁区切りあり)、月間サマリー、凡例が表示される
- [ ] 週タブ・月タブとも、記録が1件も無い期間では「この期間の記録はまだありません」が表示される

### 設定画面

- [ ] `/app/settings` を開くと、スマホでは「戻る」+「設定」の見出し(日週月の切り替えは表示されない)、PCでは通常のヘッダー(日週月の切り替え+「設定」が選択中の見た目)になる
- [ ] アカウント欄に登録中のメールアドレスが表示され、「メールアドレス」「パスワードを変更」からそれぞれの画面に進める
- [ ] 「カロリーを記録する」のスイッチを切り替えると、即座にAPIが呼ばれ(role="switch"のaria-checkedが変わる)、トーストが出る。オフにした状態で日・週・月タブを開くと、カロリーの項目が表示されない
- [ ] サポート欄の「利用規約」「プライバシーポリシー」「ライセンス」がそれぞれ別タブで開き、「お問い合わせ」がメールソフトを起動する
- [ ] 「退会する」への導線と、退会後30日間の保管についての説明文が表示される

### メールアドレスの変更

- [ ] `/app/settings/email` で新しいメールアドレスと現在のパスワードを入力し「確認コードを送る」を押すと、確認コード入力の画面に進む(ターミナルのログにコードが出力される)
- [ ] 誤ったパスワードではエラーが表示され、コードは送信されない
- [ ] すでに使われているメールアドレスを入力するとエラーが表示される
- [ ] 確認コードを入力して「変更する」を押すと完了表示になり、「設定に戻る」で設定画面に戻る。ログアウトして新しいメールアドレスでログインできる

### パスワードの変更

- [ ] `/app/settings/password` で現在のパスワードと新しいパスワード(8文字未満はエラー)を入力し「パスワードを変更する」を押すと完了表示になる
- [ ] 誤った現在のパスワードではエラーが表示される
- [ ] 変更後、別のブラウザ(または別のプロファイル)でログインしていた場合はログアウトされ、変更した画面はログインしたままになる。新しいパスワードでログインできる

### 退会・取り消し

- [ ] `/app/settings/withdraw` の説明(3項目)を確認し、パスワードを入力して「退会する」を押すと、トップページに「退会の手続きが完了しました。ご利用ありがとうございました。」と表示される
- [ ] 退会後、同じメールアドレス・パスワードでログインすると、`/app` に「退会を取り消しました」のトーストが1回だけ表示される(画面を再読み込みしても再表示されない)
- [ ] 退会中のメールアドレスで新規登録すると、既存の「登録済み」のエラーになる

### 利用規約・プライバシーポリシー・ライセンス

- [ ] `/terms`・`/privacy`・`/licenses` を開くと、共通のヘッダー(サービス名のみ)と読みやすい幅の本文が表示される
- [ ] `/terms` の第9条2項、`/privacy` の8章に、退会後30日間の保管・取り消しの記載がある
- [ ] `/licenses` にフォント(SIL Open Font License 1.1)とアイコン(ISC・MIT)のライセンス全文が表示される
