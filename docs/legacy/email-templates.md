# 旧リポジトリの認証メールの文面(参照用)

旧リポジトリ(Amplify版)の `amplify/auth/custom-email-sender/templates.ts` から、新リポジトリでも使う3種類の文面を抜き出したもの。有効期限は新しい仕様(10分)に合わせて書き換えること。

## メールアドレスの確認(新規登録時)

- 件名: 【shukanlog】メールアドレス確認コード
- 本文:
  ```
  shukanlogにご登録いただきありがとうございます。
  以下の確認コードを画面に入力し、登録を完了してください。

  確認コード: {code}
  有効期限: 10分

  このメールに心当たりがない場合は、このメールを破棄してください。
  ```

## パスワードの再設定

- 件名: 【shukanlog】パスワード再設定コード
- 本文:
  ```
  パスワード再設定のリクエストを受け付けました。
  以下の確認コードを画面に入力し、新しいパスワードを設定してください。

  確認コード: {code}
  有効期限: 10分

  このメールに心当たりがない場合は、パスワードは変更されませんので、
  このメールを破棄してください。
  ```

## メールアドレスの変更

- 件名: 【shukanlog】メールアドレス変更の確認コード
- 本文:
  ```
  メールアドレスの変更手続きのため、確認コードが必要です。
  以下の確認コードを画面に入力してください。

  確認コード: {code}
  有効期限: 10分

  このメールに心当たりがない場合は、このメールを破棄してください。
  ```
